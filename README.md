# Power BI Sales Dashboard

This project presents an interactive sales dashboard built using Power BI.

## Features

* KPI tracking (Total Sales, Orders, Customers)
* Sales trend analysis over time
* Category & segment-wise performance
* Interactive filters (Region, Category)

## Tools Used

* Power BI
* DAX
* Data Visualization

## Dataset

Superstore Sales Dataset

## Insights

* Technology category generates highest revenue
* Consumer segment contributes the largest share
* Sales show an overall upward trend
